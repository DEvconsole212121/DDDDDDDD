# Contributing

Real-world issues and independently reproducible examples are welcome. Please do not submit private user data or credentials.

1. Open an issue with a minimal HTML reproduction and expected results.
2. Create a branch, add a regression test, and submit a pull request.
3. Run `python -m unittest discover -s tests -v` before proposing a change.
4. Explain potential false positives. Be respectful of all contributors.

We are looking for accessibility expertise, Arabic-script internationalization experience and maintainers of bilingual websites.
